## How to use ChatGPT for this

1. Start **one new chat** and paste the setup message below first. Keeping everything in one chat keeps the people and the cockpit consistent.
2. Then paste one image prompt at a time, like `Image r_struggle_1: ...`.
3. If a result has a visible face, blood, a logo or broken hands, reply **"Regenerate, keep everything the same but fix: …"**.
4. Download each image you like and rename it exactly, e.g. `r_struggle_1.png`.
5. Optional: if you have Sora or another image-to-video tool, you can animate any image for 5 to 8 seconds and save it with the same name as `.mp4`. The video uses the clip instead of the still.
